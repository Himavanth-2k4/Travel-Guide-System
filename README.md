# 🌍 Travel Guide System – Discover India Like Never Before

The **Travel Guide System** is a fully responsive, intuitive, and user-centric web application developed to help users explore India’s most iconic and culturally diverse destinations. This platform allows travelers to discover tourist spots, read engaging travel blogs, share personal reviews, and seamlessly plan their trips.

---

## 🔧 Technologies Used

- **Frontend**: HTML, CSS, JavaScript, Bootstrap  
- **Backend**: PHP  
- **Database**: MySQL (managed using PHPMyAdmin)

---

## ✨ Core Features

- 🏞️ **Destination Explorer**: Browse detailed listings with images and descriptions of popular Indian travel destinations  
- ✍️ **Travel Blogs**: Read and post informative travel blogs to enhance your journey  
- ⭐ **Review System**: Users can leave feedback and rate destinations  
- 👤 **User Authentication**: Secure user registration and login functionality  
- 🛠️ **Admin Dashboard**: Admins can manage destinations, blogs, and user feedback  
- 📱 **Responsive Design**: Fully optimized for desktops, tablets, and mobile devices  

---

## 🎯 Project Objectives

This project aims to provide a comprehensive and engaging platform for both travelers and administrators. It focuses on:

- Delivering a clean and intuitive **UI/UX**  
- Enabling easy content creation and management  
- Offering a structured approach to travel planning  
- Bridging the gap between users and cultural discovery across India

## 🚀 Getting Started

To run the project locally, follow these steps:

### 1. Clone the Repository

```bash
http://localhost/Travel%20gUIDE%20System
```
### 2.Set Up the Database
  Open PHPMyAdmin

  Import the provided .sql file to create the database and tables

### 3. Configure Database Credentials
  Open the PHP configuration file (e.g., config.php)

  Update the database host, username, password, and database name as per your local setup

```bash
$host = "localhost";
$user = "root";
$password = "";
$database = "travel_guide";
```
### 4. Launch the Project
Use XAMPP, WAMP, or MAMP

  Place the project folder inside the htdocs directory

  Open your browser and navigate to http://localhost/travel-guide-system
